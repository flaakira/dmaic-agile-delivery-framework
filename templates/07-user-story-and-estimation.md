# User Story & Story Point Guide

**Hierarchy:** Project → Feature → Story → Story points

## User story template
> **As a** [type of user], **I want** [goal] **so that** [benefit].

**Acceptance criteria (Given / When / Then)**
- Given …, when …, then …

**Definition of done**
- [ ] Meets acceptance criteria
- [ ] Data validated against source
- [ ] Demoed to the requester (UAT)
- [ ] Documentation / training note updated

## Story point scale
| Points | Meaning |
|---|---|
| 1 | Done in less than a day |
| 2 | Done in 1 day |
| 3 | Done in 2 days |
| 5 | Done in a week |
| 8 | Done in 2 weeks |
| 13 | Too big: split into smaller stories |
