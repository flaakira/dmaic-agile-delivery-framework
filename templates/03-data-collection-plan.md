## Measurement System Analysis (MSA) checklist
Before trusting the baseline, confirm the data measures what you think it does.
- [ ] Two people measuring the same item get the same result (repeatability / reproducibility)
- [ ] Definitions are written down and used the same way by every team
- [ ] No duplicate, missing or default values hiding real problems
- [ ] Timestamps are consistent (time zones, entry date vs. event date)
- [ ] Spot check: N records traced from source to report
